# Reproducibility Notes

## Current reproducibility status

This repository is partially reproducible, but not yet fully standardized.

## What is already present

- full research notebook with preprocessing, training, and evaluation
- saved result summary files generated by the notebook:
  - `realistic_loo_summary.csv`
  - `realistic_timelike_summary.csv`
  - `time_like_l2_results.csv`
- saved model and feature artefacts such as:
  - `l1_model.pkl`
  - `l1_calibrated.pkl`
  - `l1_threshold.pkl`
  - `l1_features.pkl`
  - `l2_model.pkl`
  - `l2_features.pkl`
  - `robust_scaler.pkl`

## Reproducibility gaps

### 1. Package versions are not pinned
The notebook installs libraries directly, but reproducibility is weaker when versions are not fixed.

### 2. Dataset acquisition is not scripted
The notebook assumes the CIC-IDS2017 CSV files already exist in Google Drive and are ready to load.

### 3. Final result artefacts are not yet organized cleanly
Important summary tables are produced and saved by the notebook, but they should be committed in a dedicated `results/` folder with clearer naming.

### 4. Environment is Colab-dependent
The workflow depends on mounted Google Drive paths and should be documented more explicitly for users running the experiment elsewhere.
